# 基于快反镜的甲烷扫描成像软件系统开发

## 0 项目背景与需求

- 目标：我正在开发一个基于快反镜扫描与TDLAS-WMS方法的甲烷成像系统，本项目的核心目标是开发一个FPGA下位机与配套的QT C++上位机。

- 系统介绍：系统结构如下，电路板通过DAC输出WMS调制信号（低频锯齿波+高频正弦波），控制1653.7nm激光器，激光器发射激光打到快反镜上，快反镜通过扫描控制激光出射指向，发射的激光经过气体吸收以及背景反射，快反镜接收回波信号并通过离轴抛物面镜聚焦，最后由光电探测器进行接收，转换成电信号输出给电路板，由ADC进行采样。电路板内的FPGA对采样信号进行解调，得到一次谐波和二次谐波，然后融合快反镜反馈的角度信息，一起发送给上位机。上位机接收FPGA发送的数据，重建并显示浓度图像。另外，上位机也可以控制FPGA下位机的各种参数、启停等。

## 1 FPGA下位机

- 需要实现的主要模块：1）快反镜扫描控制与角度数据反馈模块；2）数据采集与解调模块；3）WMS调制信号生成模块；4）谐波与快反镜角度融合
- 快反镜扫描控制与角度数据反馈模块（可参考快返镜现有工程）：1）接收上位机发送的扫描或者角度偏转等参数，对快反镜做相应的控制（扫描频率、扫描角度范围、扫描波形、静态偏转等）；2）接收快返镜反馈的角度数据；
- 数据采集与解调模块（可参考DILA现有工程）：1）控制ADC采集探测器输出的气体吸收信号（但由于目前的电路板暂时没有ADC，因此这部分功能不用实现，直接使用基于HITRAN模拟的数据即可，存储到FPGA中作为ADC的输入）；2）对ADC采集的信号使用正交锁相放大器进行解调，输出1f和2f信号；3）接收上位机发送的参数控制指令，对相关的参数进行设置，例如采样率、滤波器阶数、截止频率等等，尽可能多留一些可设置参数，便于后续测试时对最优参数进行选取。
- WMS调制信号生成模块：1）生成低频锯齿波+高频正弦波调制信号，驱动DAC输出；2）接收上位机的控制指令设置参数，例如锯齿波和正弦波的频率、调制深度等等；3）由于当前的电路板上没有DAC，因此这部分内容不用实现，这里只是做一个说明。
- 谐波与快反镜角度融合：本项目的重点是实现浓度数据（即二次谐波峰值，其与气体浓度成正比）和快返镜扫描轨迹的融合，进而得到气体的扫描图像。这一部分我暂时没有更多的想法，你帮我设计一个合理的实现方案，例如可以采用加时间戳或者其他的方式等。
- 关于通信方式：1）FPGA与快反镜之间的通信参考快反镜现有工程（引脚配置使用相同的即可）；2）FPGA与上位机之间的通信，电路板上有UART-USB以及USB3.0两个通信接口，两个接口的通信速率、接口信息等内容可以在资料文件夹“E:\Work\甲烷巡检系统\盘A_ACX750-CH569 USB3.0开发板标准配套资料”中查找。本项目的数据量，是不是得用USB3.0进行传输？
