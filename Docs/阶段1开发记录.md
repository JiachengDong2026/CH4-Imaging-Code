# 阶段 1 开发记录

## 已完成的第一批功能

- 将既有 DILA 工程中已验证的 12,800 点、16 位 HITRAN 仿真波形导入本项目，并记录来源、生成条件和 SHA-256；
- 固定第一版数据基线为 25.6 MSPS、2 kHz 光谱扫描、200 kHz 调制，满足“采样率必须与 ROM 元数据一致”的需求；
- FPGA 接入偏置/增益校正、同源 1f/2f NCO、四路正交混频、3 级 CIC×8、16 抽头 FIR、16 点平滑、扫描分帧和 WMS 峰值提取；
- FPGA 接入 shadow 参数、检查/整体提交、启停命令、48 字节融合点封装、921600 UART 响应优先调度和最高 500 点/秒的限速；
- Qt 接入 Mock 与原生 Windows 串口、串口命令排队、50×64 Z 字仿真、轨迹、A1/A2/A2÷A1、二维相对甲烷图像及 CSV 会话记录；
- 图像直接按融合点携带的角度落格，范围随快反镜配置变化，奇数行不做人工翻转。

## 已验证结果

- Vivado 2020.2 综合：0 error、0 critical warning；当前映射 226 个 DSP48E1、8 个 RAMB36E1；
- XSim DILA 端到端：连续得到 3 个非零 A1/A2 的有效光谱特征；
- XSim 应用协议：接受 3 类合法帧并拒绝 1 个坏 CRC 帧；
- Qt Debug：协议和阶段 1 数据测试通过；离屏 UI smoke test 在当前 Qt/Windows 环境中未正常退出，尚未计为通过。

## 当前边界

当前完整 FPGA 顶层已接入快反镜差分引脚和 4.608 Mbps 原生链路；必须完成实物反馈、轨迹和融合图像验证后，才能把阶段 1 标记为完成。完整 DILA 顶层可以布线，但最终 WNS 约 -65.147 ns，必须将并行幅值/FIR 长路径改成流水或时分复用结构后才能作为可靠硬件版本。

为先验证上位机与下位机通信，已经另外生成 `FPGA/build/bitstream/ch4_uart_comm_test.bit`。该固件只连接 W19、D21、L21、M21，在 FPGA 内生成 500 点/秒的 50×64 融合测试数据；最终布线 WNS 为 +12.594 ns，DRC 无错误。它不包含 DILA 数据通路，也不驱动快反镜。

下一批工作是：完成真实快反镜上板联调并收敛完整 DILA 顶层时序；阶段 1 验收后再提交代码，进入 USB3.0 通信阶段。真实 ADC/DAC 和真实浓度标定仍属于后续阶段。
