# 测试与验收方案

## 阶段 0

在根目录执行：

```powershell
.\Build.ps1 -Target All -Config Debug
.\Build.ps1 -Target Package -Config Release
```

通过条件：

1. 生成文件与共享定义完全一致；
2. CRC 标准向量为 `0x29B1`；
3. Qt 能处理固定帧、拆包、粘包、垃圾前缀、坏 CRC 后恢复；
4. FPGA 完成综合，XSim 正确接受三类合法帧并拒绝坏 CRC；
5. 发布目录 EXE 在不配置 Qt 环境变量的情况下能启动；
6. 所有生成输出均位于本项目目录并被 `.gitignore` 正确排除。

## 阶段 1 当前自动测试

当前已经加入：

1. HITRAN ROM 经 25.6 MSPS 读出、NCO、四路混频、CIC、FIR、平滑、2 kHz 分帧和 WMS 特征提取的 XSim 端到端测试；
2. Qt 固定融合点解析、实际角度网格映射、50×64 完整 Mock Z 字扫描和无界面启动测试；
3. 原阶段 0 的统一协议合法帧/坏 CRC FPGA 仿真和 Qt 拆包恢复测试继续保留。
