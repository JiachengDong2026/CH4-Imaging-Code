# 阶段 0 交付说明

## 范围

本阶段只完成工程骨架和协议冻结，不声称已经实现快反镜闭环、DILA 实时处理、USB3.0、真实 ADC/DAC 或真实浓度标定。

## 交付物

1. 规范目录、根级和分工程构建脚本、Git 忽略规则；
2. `Shared/protocol.yaml`、`Shared/register_map.yaml` 两份唯一源定义；
3. 自动生成的 C++/Verilog 常量、通信协议文档、寄存器文档和固定测试帧；
4. 可综合的 FPGA 顶层骨架、统一应用帧接收器和协议仿真；
5. Qt 6.11.2 / C++20 白色界面骨架、协议编解码器和自动测试；
6. VS Code 构建、F5 调试和 Code Runner 运行配置；
7. 旧工程只读复用记录。

## 冻结决定

- 应用帧固定为 `A5 5A`、小端、CRC-16/CCITT-FALSE；CRC 从 version 覆盖到 payload 末尾；
- 响应不再使用 `type | 0x80`，而是保持 type 并设置 `IS_RESPONSE`，这样完整的 `0x00～0x7F` 消息分组可长期扩展；
- UART 应用载荷上限 1024 字节，USB 应用载荷上限 4080 字节；
- 48 字节融合点布局固定，角度为 Q13，时间为 50 MHz tick，`A2/A1` 在 Qt 中计算；
- 配置参数写入 shadow 区，经验证后在安全边界整体提交；
- 阶段 1 参数基线暂定 64 kSPS 仿真采样、5 Hz 低频光谱扫描、快反镜反馈 2500 Hz。采样率必须和 ROM 元数据一致。

## 验证方法

根目录运行 `.\Build.ps1 -Target All -Config Debug`。脚本依次检查共享定义、Qt 协议测试、FPGA 语法/综合和 FPGA 协议仿真；任何一步失败都会返回非零状态。
